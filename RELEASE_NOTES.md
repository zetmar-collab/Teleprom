# Teleprom v1.0.0

Pierwsze wydanie aplikacji Teleprom.

## Zawartość

- aplikacja telepromptera Python/Tkinter dla Windows i macOS
- import plików TXT, SRT, MD, DOCX i RTF
- edytor do wklejania tekstu
- modalne okno promptera z płynnym przewijaniem
- regulacja czcionki, rozmiaru, prędkości, marginesu, kolorów i wyrównania
- tryb pełnoekranowy, pauza, reset, ręczne przewijanie i odbicie lustrzane
- instalatory i skróty dla Windows oraz macOS
- gotowa paczka `Teleprom.zip`
